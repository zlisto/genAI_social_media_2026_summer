Homework 2: Final Project Video Reel Agent

Due: Friday, August 7, 2026 at 11:59 PM

In this assignment you will write your final project proposal and then build an agent that turns your proposal into a short video reel. Submit a public GitHub repository with your code and grading files, and upload the reel MP4 file on the grading website (do not put the video on GitHub).

Agent Requirements

Your agent reads your project proposal file project_proposal.md, builds a video reel about your final project, and saves slides, audio, and grading artifacts. All LLM output of the agent uses gpt-5.6-luna. All TTS output of the agent uses tts-1-hd. Your final submission must include:

  1. Project Proposal: Describe your final project (the problem it addresses, the audience it targets, scope of work, etc.). It should be a good, feasible project for this course—not vague or impossible to build in the remaining weeks. This file is the input to your agent for creating the video reel.
  2. Slide Plan: A 4–6 slide plan for your video with structured Pydantic output. Each slide entry must include a slide description (what is on screen: text and visuals) and the narration text spoken for that slide.
  3. HTML Slides: Write each slide as an HTML file. At least one slide must be a real visual made with HTML/CSS and/or inline SVG (illustration, CSS art, infographic, poster layout)—not just text with a tiny icon. Do not use any image generation models or stock photos as the main visual. The image must be code that is rendered into an image.
  4. Narration + TTS: For each slide, use the narration text from the slide plan and synthesize speech with OpenAI TTS model tts-1-hd. Optionally, you may use a Google Gemini API key instead for more expressive / interesting voices. Keep each clip short (about 15 seconds or less) to control cost. Max 6 slides.
  5. Slide critique and feedback: The agent must enhance each slide. It critiques each slide and narration, provides improvement suggestions, and uses those suggestions to make a revised version of the slide and narration. Save the critique and feedback so graders can see what changed.
  6. Parallelization: Design your agent to generate the slides and audio and their enhancement in parallel. This will speed up the production process.
  7. Video Reel: Stitch the slides and audio into a ~30–60 second video file and upload it to the grading website.
  8. Agent Flow Diagram: Include an image file showing your agent flow. Include nodes for key functions and tools, and the inputs and outputs for each stage.

Stack Requirements

  • Python + PydanticAI for the agent, with a main script such as reel_agent.py that you can run from the terminal to generate your video from your project proposal.
  • Include requirements.txt with required packages.
  • Use a local .env file which has your OPENAI_API_KEY. Do not commit API keys to GitHub.

Submission

Push your project to a GitHub repository and submit the repository URL on the grading website. Upload reel.mp4 on the grading website as well. The repo must include an ai_grading/ folder at the repository root with the outputs below so an AI grader can score your work without digging through the whole tree.

Required layout (folder names and filenames must match):

your-repo/ ├── README.md (how to install, set env vars, and run) ├── requirements.txt ├── .gitignore (must include .env and __pycache__) ├── project_proposal.md (your final project proposal) ├── reel_agent.py (or equivalent main entry for your agent) ├── slides/ (HTML slides used in the reel) └── ai_grading/ ├── slide_plan.json (slide descriptions + narration text) ├── critique_feedback.json (critique and improvement feedback per slide) └── agent_flow.png (or .svg — diagram of your agent)

What goes in ai_grading/

  • slide_plan.json — the slide plan from your run. Each slide needs a description (on-screen content) and narration text.
  • critique_feedback.json — structured critique and improvement suggestions for each slide and narration, plus what changed in the revised versions.
  • agent_flow.png (or .svg) — a clear diagram of your agent flow.

Do not commit secrets or huge media dumps. The MP4 belongs on the grading website, not as a required GitHub file.
